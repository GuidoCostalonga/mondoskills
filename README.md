# MondoSkills.it

Catalogo di 7.600 skill per Claude e ChatGPT, con filtri su ogni colonna e il testo di installazione da copiare.

Il sito è una sola pagina statica (`index.html`), pubblicata con GitHub Pages sul dominio mondoskills.it.

MondoSkills è un archivio: raccoglie skill pubblicate da altri, con il collegamento alla fonte originale. Dati aggiornati al 14 ottobre 2026.
